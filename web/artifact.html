    奇诺与艾鲁梅斯：由立绘转换的 64×64 皮肤（纤细手臂模型），以及用方块模型重建的摩托车。

    在 Minecraft 里放映

    这个页面用网页渲染器实时播放，和游戏内的数据包使用同一份剧本、同一套皮肤与模型，声音也一样：356 句日语配音（语音合成）、原版音效、自制的引擎声与钢琴配乐。要在游戏里放映：

    1. Java 版 1.21.9 或更新，新建「超平坦 · 虚空」世界并开启作弊；
    2. 装入资源包 奇诺之旅_资源包.zip，把 奇诺之旅_数据包.zip 放进存档的 datapacks；
    3. 运行 /function kino:setup 搭建场景，然后 /function kino:play 开始放映（/function kino:scenes 可跳到任意一场）。

    镜头由数据包控制，放映时不要按 F1（字幕与遮罩属于界面层）。日语配音走游戏的「语音/旁白」音量，配乐走「音乐」，放映前请确认它们没有关掉。
